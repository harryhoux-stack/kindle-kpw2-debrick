# Kindle Paperwhite 2（KPW2）救砖指南

## 一、当前诊断结论

- 电脑已经识别到 Kindle（设备管理器里显示 "Kindle Internal Storage"，USB ID 1949:0004），早期磁盘容量显示 **0 字节、无分区、无媒体**。
- 这说明：**底层引导程序（U-Boot）是好的**，只是 eMMC 存储上的分区表/系统被刷坏了。
- 这属于"半砖"：不需要换主板，把系统刷回去即可救活。
- **好消息：本次实测已经通过不拆机方案成功救活（详见"方案 C"）**。如果再次遇到同样的砖，直接按方案 C 操作，无需拆机、无需串口线。

## 〇、本次实测成功记录（2026-08-06）

设备最终确认是 **KPW2**（序列号 905A 开头），刷的是 CrackDroid 安卓系统（Ygjsz_ 制作）失败导致变砖。

成功路径：

1. 设备开机后（或按住电源键 15 秒）进入 **Android fastboot 模式**（USB ID `18D1:4E40`，设备名 "Android Bootloader Interface"）。
2. 安装 Google 官方 USB 驱动（`android_winusb.inf`，含 `18D1:4E40` 条目），Windows 即可识别 fastboot 设备。
3. 从 kdroid.club 网页存档获取 **CrackDroid 官方 KPW2 刷机包**（`kpw2.191115.zip`，约 466MB，内含 `fastdownload.exe` + 系统镜像）。
4. 运行刷机包里的 `fastdownload.exe`，检测到设备后选择 **选项 4「转换为原始系统(Kindle)」**。
5. 工具自动写入原生系统镜像（system.bin）和内核（kernel.bin），完成后设备自动重启。
6. 重启后设备恢复为 Kindle 原生 USB 存储模式：MBR 分区表、约 3.37GB、FAT32、卷标 "Kindle"，含 `documents`/`fonts`/`system` 目录。

所需文件位置（本仓库内已随附，可直接下载）：

- Google USB 驱动：本仓库 `tools/drivers/usb_driver_r13-windows.zip`（解压后为 `android_winusb.inf`）
- fastboot 工具：本仓库 `tools/fastboot/platform-tools.zip`（解压后为 `fastboot.exe`）
- 备用 MfgTool：本仓库 `tools/mfgtool/popcorn.7z`
- CrackDroid 刷机包（约 466MB，超出 GitHub 限制）：下载链接见 `tools/软件清单.md` 第 2 节，解压后运行其中的 `fastdownload.exe`

注意：fastboot 会话有约 5 秒超时，若 `fastboot devices` 能看到设备但命令超时，需重新让设备进入 fastboot（按住电源键 15 秒）后立即执行。

## 二点五、方案 C：CrackDroid 官方恢复工具（实测成功，不拆机）

适用对象：刷过 CrackDroid 安卓系统（Ygjsz_ 制作，支持 KPW2/3/499/Voyage/Oasis）且刷失败的 Kindle。

### C.1 准备文件

1. **CrackDroid 官方刷机包**：文件名 `kpw2.xxxxxx.zip`（机型不同前缀不同，如 `kindle8.230118.zip`）。当前可用的 KPW2 包 `kpw2.191115.zip` 已保存在 `C:\tmp\kindle_rescue\kpw2.191115.zip`，解压到任意目录。
2. **Google USB 驱动**：`C:\tmp\kindle_rescue\usb_driver\usb_driver\android_winusb.inf`。
3. 刷机包内自带 `fastdownload.exe`、`system.bin`（原生系统镜像）、`kernel.bin` 等文件。

### C.2 安装驱动

1. 设备管理器中右键 "Android Bootloader Interface"（USB ID `18D1:4E40`）→ 更新驱动 → 手动选择 `android_winusb.inf`。
2. 若没有此设备，先让 Kindle 进入 fastboot 模式（见 C.3）再安装。
3. 安装驱动需要管理员权限，可能会弹出系统 UAC 确认框，点"是"。

### C.3 让设备进入 fastboot 模式

1. 用数据线连接 Kindle 和电脑。
2. **按住电源键约 15 秒**，设备进入下载/fastboot 模式。
3. 若设备屏幕出现 `[enter] updating mode` 或 `[start] download mode` 文字，点一下该文字。
4. 在命令行验证：`fastboot devices` 应显示类似 `02722XXXXXXXL3  fastboot`。
5. **注意**：fastboot 会话约 5 秒超时。若 `fastboot devices` 能看到设备但执行命令超时，说明会话已退出，需要重新按住电源键 15 秒。

### C.4 执行恢复（转换为原生系统）

1. 进入刷机包解压后的目录（含 `fastdownload.exe`）。
2. 运行 `fastdownload.exe`，等待出现菜单：

```
###安卓系统升级，当前系统：原生系统
###1.升级安卓(Upgrade)；
###2.升级安卓&重置(Upgrade&Wipe)；
###3.转换为安卓系统(Android)；
###4.转换为原始系统(Kindle)；
###0.退出(Exit)。
###请选择(0-4):
```

3. 输入 **4** 回车（转换为原始系统/Kindle）。
4. 工具自动下载 system.bin 和 kernel.bin 到设备，显示进度条到 100%，随后自动重启。
5. 等待设备重启完成，Windows 应识别到 Kindle 原生存储盘（MBR、约 3.37GB、FAT32、卷标 "Kindle"）。

### C.5 验证

- 电脑上应出现 Kindle 盘，内含 `documents`、`fonts`、`system` 目录。
- 安全弹出后，Kindle 屏幕应正常进入原生系统主界面。

### C.6 注意事项

- 刷机过程中**不要拔掉 USB 线**。
- 若之前刷安卓时把分区表也写坏了（磁盘显示 0 字节/无媒体），选项 4 会一并恢复分区表和文件系统（本次实测即为此情况，一次成功）。
- 若设备进不了 fastboot（如按住电源键后无反应），可尝试先长按电源键 40 秒强制重启，再按 15 秒进入下载模式。

## 三、方案 A：串口救砖（推荐）

### 3.1 需要的工具

1. **USB-TTL 串口转换器**：务必支持 1.8V 电平（常见的有 CH340、CP2102、FT232 等带电平跳线的型号）。淘宝搜"USB TTL 1.8V"即可，一般送杜邦线。
2. **拆机工具**：塑料撬片/撬棒、小号十字螺丝刀、镊子。
3. **细导线或杜邦线**：推荐"公对母"杜邦线，母头那头可以压住焊点而不一定需要焊接；有烙铁更稳。
4. **电脑端软件**：PuTTY（也可以让我远程帮你操作串口）。

### 3.2 拆机

1. 先断开电源、拔掉 USB。
2. 用吹风机（热风）沿后盖边缘加热 1-2 分钟。PW2 后盖是塑料卡扣结构，加热后容易撬。
3. 从底部 USB 口附近用撬片沿边缘慢慢撬开后盖，注意卡扣位置，别硬掰。
4. 拧下主板固定螺丝，小心翻开主板（注意屏幕排线和电池排线，不要拉扯）。

### 3.3 找到串口焊点

- 主板上有一组丝印为 **"P800 SERIAL DEBUG"** 的方形焊盘（4 个点），背面可能标注 **TM800 / TM801**。
- 四个焊点分别是：**GND、TX（Kindle 发送）、RX（Kindle 接收）、1.8V 电源**。GND 是最小的那个焊盘。
- 具体位置请对照本目录 `测试点参考` 文件夹里的照片。
- **接线规则（关键）**：
  - Kindle 的 GND ↔ 转换器的 GND
  - Kindle 的 TX ↔ 转换器的 RX
  - Kindle 的 RX ↔ 转换器的 TX
  - **绝对不要接转换器的 VCC/电源输出到 Kindle！**

### 3.4 进入恢复菜单

1. 转换器插入电脑，确认设备管理器里出现 COM 口（端口类）。
2. 打开串口终端：**波特率 115200，8 数据位，无校验，1 停止位**（即 115200-8-N-1）。
3. 长按 Kindle 电源键开机，**在开机瞬间开始连续按回车键**（可以一直狂按）。
4. 正常情况下会看到 U-Boot 的恢复菜单，类似：

```
Menu
====
3. Load MMC0 over USB storage
4. Erase MMC0
I. Initialize Partition Table (fdisk) and format FAT
O. Format and overwrite FAT partition
E. Export FAT partition
U. Update using update*.bin file on FAT partition
M. Update using update*.bin file on FAT partition of second MMC port
D. dmesg / kernel printk ring buffer.
Q. quit
```

### 3.5 刷写官方系统

1. 按 **I**：重新初始化分区表并格式化 FAT。当前磁盘显示 0 字节说明分区表已损坏，这一步会重建分区表（**会清空 Kindle 里的所有数据**）。
2. 按 **E**：导出 FAT 分区为 U 盘。此时电脑上应出现一个可用的 Kindle 磁盘。
3. 把官方固件 [update_kindle_paperwhite_v2_5.12.2.2.bin](update_kindle_paperwhite_v2_5.12.2.2.bin)（约 217MB）复制到该磁盘**根目录**，不要改名。
4. 在电脑上**安全弹出**该磁盘。
5. 回到串口菜单，按 **U**：用 FAT 分区上的 update*.bin 更新系统。
6. 等待刷写完成（串口有进度输出），完成后设备会自动重启。
7. 重启后应进入 Kindle 全新设置的界面，救砖完成。

### 3.6 常见问题

- **进不了菜单**：调整按回车键的时机（从开机瞬间开始持续狂按），多试几次。
- **复制固件时大量 I/O 错误或速度极慢**：先按 I 重新分区格式化再试；如果依然大量报错，说明 eMMC 存储芯片可能物理损坏（需要芯片级维修）。
- **屏幕没显示但串口有输出**：正常，以串口输出为准。
- **串口乱码**：检查波特率是否为 115200、TX/RX 是否接反、转换器电平是否为 1.8V（3.3V 一般也能用但不推荐）。

## 四、方案 B：底层 USB 下载模式（免焊接，备用）

### 4.1 原理

KPW2 的处理器（i.MX6SL）内置"工厂下载模式"（SDP）。通过短接主板上的测试点强制进入该模式后，电脑会把它识别为 Freescale 设备（"SE Blank MEGREZ"，VID 15A2，PID 0063），然后用 MfgTool 把救砖内核加载进内存，再通过 fastboot 刷写分区。

### 4.2 步骤

1. 拆机（同 3.2）。
2. 找到测试点：**CR501**（右侧矩形焊盘）和 **TP508**（3.3V 测试点）或 **TP1706**（1.8V 测试点）。位置对照 `测试点参考` 文件夹照片。
3. 用镊子/回形针/跳线短接 **CR501 右侧焊盘与 TP508**。
4. 保持短接，同时接上 USB 线，**按住电源键约 15 秒**重启。
5. 电脑设备管理器应出现 "SE Blank MEGREZ"（Freescale HID 设备）。
6. 运行 Windows 版 **MfgTool.exe**，点 Start，等待加载完成（只加载到内存，不改写存储）。
7. 救砖内核启动后设备进入 fastboot 模式，后续用 fastboot 刷入从官方固件解包出的分区镜像（kernel / rootfs 等，这一步需要 kindletool 解包，我可以协助完成）。

### 4.3 注意事项

- 短接时务必只碰目标焊点，不要碰到旁边元件，更不要同时短接多组。
- 如果短接后电脑没有任何新设备出现，检查接触是否可靠、电源键按住时长是否足够。
- 方案 B 比方案 A 步骤多、容易出错，建议优先方案 A。

## 五、重要提示

- U-Boot 存放在独立的 ROM 里，正常刷系统不会损坏它；只要 U-Boot 还活着，本指南的方法就能救回设备。
- 请先确认设备确实是 **KPW2**：翻到背面底部边缘看序列号，PW2 序列号通常以 90 开头（如 9017、90D4）。如果不是 KPW2，固件和部分操作会不同，先告诉我再动手。
- 刷机前建议先把 Kindle 充电到一半以上，避免中途断电。
- 所有操作都在你自己的设备上进行，风险自担；本指南步骤来自社区多人验证过的方案。
