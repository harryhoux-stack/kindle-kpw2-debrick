## 4. 设备模式速查表（USB ID）

| USB ID | 含义 | 说明 |
| --- | --- | --- |
| `1949:0004` | Kindle 原生 USB 存储模式 | 正常连接电脑时出现；若 0 字节说明分区表损坏 |
| `18D1:4E40` | Android fastboot 模式 | CrackDroid 引导层，刷机工具在此模式下工作 |
| `15A2:0063` | i.MX6 SDP 下载模式 | MfgTool/imx_usb_loader 引导用（需短接测试点） |
| `1949:DEAD` | Kindle HID | 充电/按键相关 |

## 5. 关键命令速查

```powershell
# 验证 fastboot 设备（应显示序列号 + fastboot）
fastboot devices

# 读取设备信息
fastboot getvar version
fastboot getvar product
fastboot getvar serialno
fastboot getvar bootmode

# 运行官方刷机工具（在解压后的刷机包目录内）
fastdownload.exe
```
